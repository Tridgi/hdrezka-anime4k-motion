## Возможности плеера

**Anime4K** работает в том же отдельном окне плеера, без необходимости устанавливать внешний видеоплеер. Доступные режимы: **выключено, A, B, C, Light**. Они отличаются обработкой и нагрузкой, а не являются уровнями качества по возрастанию.

**Плавность изображения** настраивается независимо: **выключено, 60 FPS, 120 FPS, 165 FPS** (последний режим экспериментальный). Промежуточные кадры рассчитываются SVPflow/VapourSynth с использованием OpenCL. Для работы нужен совместимый GPU-драйвер.

Также доступны выбор качества и озвучки, субтитров, скорости, громкости, серий, сохранение позиции просмотра и пропуск опенинга (по умолчанию 85 секунд, настраивается). Интерфейс плеера скрывает элементы управления при бездействии.

### Начальные настройки

| Сценарий | Рекомендуется попробовать |
| --- | --- |
| Умеренная нагрузка и плавность | Anime4K Light + 60/120 FPS |
| Более чёткие контуры | Anime4K A |
| Слишком резкая обработка | Anime4K B |
| Шумные или пережатые исходники | Anime4K C |
| Проверка оригинального качества | Anime4K выкл. / плавность выкл. |

> **Важно:** Anime4K — не DLSS, не RIFE и не восстановление несуществующих деталей. Сглаживание и интерполяция могут создавать артефакты. Режим 165 FPS — целевой, а не гарантированный результат. На производительность влияют GPU, исходный FPS, разрешение и поток.

## Системные требования

| Компонент | Требование |
| --- | --- |
| ОС | Windows 10, версия 2004 (сборка 19041) или новее; Windows 11 |
| Архитектура | x64 (Windows ARM64 и x86 не являются целевыми платформами portable-релиза) |
| Графика | Direct3D 11 для видеорендеринга |
| Интерполяция | Совместимый OpenCL-драйвер/устройство для SVPflow |
| Сеть | Доступ к выбранному зеркалу HDRezka, CDN и GitHub для обновлений |
| Установка | .NET 8 и Windows App SDK входят в self-contained ZIP |

Пример конфигурации локального тестирования: **NVIDIA P106-100 6 ГБ, Intel Core i5-6500, 2560×1440 / 165 Гц**. Это не перечень гарантированно поддерживаемого оборудования. Обновлённые CI-тесты проверяют низкие разрешения 426×240/854×480; результат реального воспроизведения зависит от конфигурации.

## Установка 2.1

1. Откройте **[стабильный релиз v2.1.0](https://github.com/Tridgi/hdrezka-anime4k-motion/releases/tag/v2.1.0)**.
2. Скачайте **`HDREZKA-Anime4K-Motion-2.1.0-win-x64.zip`** и, при необходимости, **`SHA256SUMS.txt`** для проверки архива.
3. Распакуйте **весь** архив в отдельную папку с правом записи (например, `D:\Apps\HDREZKA`). Не запускайте приложение непосредственно из ZIP.
4. Запустите `HDREZKA.App.exe`. Не удаляйте каталоги `runtime`, `motion`, `shaders` и файл помощника обновлений.
5. Укажите рабочее HTTPS-зеркало в настройках и войдите в свой аккаунт, если требуются комментарии и персональные функции.

**Если у вас уже стоит тестовая сборка:** откройте **Настройки → Обновления**, выберите **Стабильный** и проверьте обновление. Если встроенная установка не срабатывает, скачайте ZIP и распакуйте в отдельную папку. Перед ручной заменой закройте приложение и при необходимости сохраните копию старой папки. Не удаляйте данные в `%APPDATA%\HDREZKA-Anime4K-Motion`.

Файлы настроек, история просмотра и прочие пользовательские данные хранятся **отдельно от portable-каталога** — в `%APPDATA%\HDREZKA-Anime4K-Motion`. Учётные записи и cookies из оригинального клиента автоматически не импортируются.

## Быстрый обзор интерфейса

**Каталог.** Выберите фильмы, сериалы, мультфильмы, телешоу или аниме; затем сортировку и жанр. Если зеркало изменило URL или ограничило доступ, результаты и ошибки могут отличаться. Приложение не гарантирует доступность каждого жанра на всех зеркалах.

**Подборки.** Поиск по названию и сетка обложек ведут к списку фильмов. «Назад» возвращает к подборкам, не перескакивая в другой раздел.

**Карточка тайтла.** Рейтинги, жанры, связанные фильмы, актёры и режиссёры дополняют выбор сезона и озвучки. Правый щелчок по серии позволяет отметить просмотренное; выбор серии и состояние просмотра независимы.

**Комментарии.** Для отправки требуется вход в аккаунт и разрешение сайта. Если зеркало отклоняет запрос (например, из-за CAPTCHA или модерации), черновик сохраняется и показывается причина, если сайт её вернул. Свои комментарии выделяются, когда их авторство удалось определить.

**Оформление.** Тема, основные цвета, режим окраски жанров и размер постеров настраиваются отдельно от плеера. Изменения сохраняются между запусками.

**Поддержка проекта.** Страница Boosty содержит прямую ссылку и QR-код; отдельного поля кода поддержки больше нет.

Полная инструкция с диагностикой — [docs/USER_GUIDE.md](docs/USER_GUIDE.md).

## Обновления и безопасность

- Стабильные релизы публикуются под тегами `vX.Y.Z`, тестовые — `test-<commit>`. Переход между каналами осуществляется в настройках приложения.
- Для обновлений используются именно **GitHub Releases** данного репозитория; загрузка проверяется по SHA-256. Helper создаёт резервную копию предыдущей установленной папки и предусматривает откат при сбое.
- Встроенный список выпусков кэшируется из-за ограничений GitHub API. Ручная проверка может временно показывать устаревшие данные.
- Каталог, плеер и комментарии работают с внешним сайтом и его зеркалами. Приложение не обходит CAPTCHA и ограничения сервиса.
- ZIP не содержит пользовательских cookies, паролей, истории, сохранённых аккаунтов и тестовых видео.

О механизме обновления — [docs/UPDATER.md](docs/UPDATER.md), о публикации — [docs/RELEASES.md](docs/RELEASES.md).
