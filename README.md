# HDREZKA Anime4K Motion v2

**HDREZKA для Windows с Anime4K, улучшением изображения 1080p → 1440p и отдельной интерполяцией движения до 60 / 120 / 165 FPS.**

Неофициальная модификация [HDREZKA for Windows от eddinwork](https://github.com/eddinwork/HDREZKA). Сохраняет каталог и привычное отдельное окно плеера, добавляет обработку изображения и плавности прямо в него. Внешний плеер для этих функций не нужен.

[English](README.en.md) · [Скачать portable](https://github.com/Tridgi/hdrezka-anime4k-motion/releases) · [Сборка](docs/BUILD.md) · [Компоненты и лицензии](THIRD_PARTY.md)

## Возможности

- **Anime4K:** выкл., A (основной), B (мягкий), C (подавление шума), лёгкий. Обработка адаптируется к размеру окна; название Anime4K не требует монитора 4K.
- **Плавность:** независимые режимы выкл. / 60 / 120 / 165 FPS. Промежуточные кадры рассчитываются по движению через open-svpflow и OpenCL.
- **Пропуск опенинга:** кнопка перемотки вперёд на 85 секунд; интервал настраивается от 1 до 600 секунд.
- **Автоскрытие курсора и панелей:** через 3 секунды без движения во время воспроизведения, в обычном и полном экране.
- Субтитры, выбор качества, скорость, громкость, позиция просмотра и навигация между сериями используют интерфейс исходного приложения.
- Русские и английские ресурсы в portable-сборке. Отдельная папка данных, без авторизации и истории разработчика.

## Запуск

1. Скачайте `HDREZKA-Anime4K-Motion-v2-win-x64.zip` из Releases.
2. Распакуйте **весь** архив в отдельную папку.
3. Запустите `HDREZKA.App.exe`. Не удаляйте `runtime`, `motion` и `shaders`.
4. Откройте видео: Anime4K выбирается сверху, плавность — отдельно снизу.

Windows 10 2004 (19041) или новее / Windows 11, x64. Для картинки нужен Direct3D 11, для интерполяции — совместимый OpenCL-драйвер. Проверенная конфигурация: NVIDIA P106-100 6 GB, Core i5-6500, экран 2560×1440 165 Гц. Совместимость с другими GPU требует проверки. .NET и Windows App SDK включены в self-contained выпуск.

## Какой режим выбрать

| Задача | Начальная настройка |
| --- | --- |
| Плавность при умеренной нагрузке | Лёгкий Anime4K + 120 FPS |
| Более выраженная обработка контуров | A + 60 FPS |
| Основной режим кажется слишком резким | B |
| Шумное или сильно сжатое видео | C; проверьте, не теряются ли мелкие детали |
| Сравнение с исходной картинкой | Anime4K выкл. |

A/B/C — разные методы обработки, а не уровни качества по возрастанию. FPS не зависит от выбора Anime4K. Полный экран на мониторе 2560×1440 выводится в этом разрешении; исходный поток при этом может оставаться 1080p.

## Ограничения и результаты проверки

Это **не NVIDIA DLSS, не RIFE и не способ вернуть детали, которых нет в исходнике**. Возможны чрезмерно выраженные контуры, сглаживание текстур и артефакты интерполяции на смене сцен.

В коротком локальном тесте 1080p24 на указанной P106-100 сочетания «лёгкий + 120 FPS» и «A + 60 FPS» прошли без пропусков в измеряемом интервале. При цели 165 FPS отображалось примерно 140–144 кадра/с с пропусками: **165 FPS — экспериментальный режим, а не гарантия производительности**. Сетевые задержки и другое видео могут менять результат. Интерполяция рассчитана прежде всего на видео с постоянной известной частотой кадров.

Исправлена авария после отключения FPS: библиотеки фоновых обработчиков удерживаются в памяти до выхода. Проверены 12 циклов переключения FPS/Anime4K, включая паузу, и ещё 30 секунд после выключения FPS.

## Личные данные и обновления

Новая версия использует `%APPDATA%\HDREZKA-Anime4K-Motion`. Она не импортирует аккаунты, cookies, историю и настройки из оригинального приложения или тестовых версий. Авторизация выполняется самим пользователем. Сборка не содержит аккаунтов, тестовых видео, журналов или дампов.

Кнопка проверки обновлений открывает Releases **этого проекта**; автоматическая установка оригинальной версии поверх модификации отключена. Приложение обращается к выбранному зеркалу и CDN для своих обычных функций; это не полностью автономное приложение. Локальные файлы можно открыть аргументом `--local-file=полный_путь`.
