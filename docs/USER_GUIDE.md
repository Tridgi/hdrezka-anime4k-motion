# Руководство пользователя HDREZKA Anime4K Motion 2.1

[← README](../README.md) · [Скачать стабильную 2.1.0](https://github.com/Tridgi/hdrezka-anime4k-motion/releases/tag/v2.1.0) · [Все изменения](../CHANGELOG.md)

> Неофициальное Windows x64-приложение. Для каталога и просмотра необходимо доступное зеркало источника. Некоторые функции зависят от аккаунта и ограничений HDRezka.

## 1. Быстрый запуск

1. Скачайте архив `HDREZKA-Anime4K-Motion-2.1.0-win-x64.zip` со страницы стабильного релиза.
2. Распакуйте архив полностью в отдельный каталог с правом записи, например `D:\Apps\HDREZKA`.
3. Запустите `HDREZKA.App.exe` из распакованной папки (не из ZIP).
4. Проверьте зеркало в настройках. Для закладок, комментариев и других возможностей аккаунта потребуется вход в HDRezka.
5. Откройте каталог или поиск, выберите фильм/сериал. Нажмите «Смотреть» и настройте качество и воспроизведение.

Важные каталоги `runtime`, `motion` и `shaders` должны оставаться в папке приложения. Разработчики не распространяют фильмы или доступ к чужим аккаунтам.

## 2. Навигация

| Раздел | Назначение |
| --- | --- |
| Главная | Тематические ленты, блок популярных фильмов, рекомендации, продолжение просмотра |
| Поиск | Поиск фильма, сериала или другого доступного контента |
| Каталог | Сортировка, категории и жанры с возможностью сброса |
| Подборки | Список тематических коллекций с поиском по названиям |
| Оформление | Тема, палитры, цвета жанров и размер карточек |
| Уведомления | Обновления отслеживаемых сериалов и ручная проверка |
| Поддержать проект | Ссылка и QR-код Boosty |
| Настройки | Зеркало, параметры приложения, обновления и история версий |

Кнопка «Назад» в заголовке и боковая кнопка мыши возвращают по истории приложения. Внутри выбранной подборки возврат сначала открывает главный список подборок. Иконка боковой панели отражает состояние меню.

## 3. Каталог и жанры

Вверху каталога расположены:

- **Сортировка**: «Новинки», «Популярное», «Скоро» и «Сейчас смотрят» (доступность результатов зависит от раздела).
- **Тип контента**: фильмы, сериалы, мультфильмы, телешоу или аниме.
- **Жанр**: варианты, найденные непосредственно на активном зеркале.
- **Сбросить**: убирает выбранный жанр.

На широком окне элементы идут одной строкой, на среднем/узком — переносятся. Горизонтальная полоса прокрутки для этого блока не нужна. Если изменили раздел, жанр выбирается заново для выбранного типа.

### Если жанр не показывает фильмы

1. Убедитесь, что другие категории каталога загружаются.
2. Сбросьте жанр и выберите другой.
3. Проверьте зеркало: сайт может отвечать страницей ограничения доступа, изменять адреса жанров или временно не обслуживать AJAX.
4. При необходимости перезапустите приложение и проверьте повторно.

Поддерживаются как адреса `/series/melodrama/`, `/films/drama/`, так и варианты с `/genre/` и некоторые числовые фильтры. Приложение не гарантирует работоспособность всех зеркал после изменений на стороне сайта.

## 4. Подборки и предпросмотр

- В «Подборках» отображается сетка с поиском по названию. Изображения обложек показываются целиком, без обрезания логотипа.
- Нажатие на подборку открывает фильмы в ней. Для возврата есть кнопка «Все подборки», а также общая кнопка «Назад».
- При наведении на карточки в каталоге и рекомендациях могут показываться рейтинги, жанры, описание и лица, когда сведения доступны.
- Дополнительные сведения подгружаются по требованию, поэтому краткая карточка может появиться раньше полного описания.

## 5. Страница фильма/сериала

На странице тайтла находятся описание, доступные оценки HDRezka/IMDb/КП, жанры и персоналии, список актёров, ссылки на франшизы и подборки, выбор озвучки/сезона/серии, рекомендации, расписание и комментарии.

**Кликабельные метки:** жанр ведёт в каталог с выбранным жанром, актёр или режиссёр — на страницу человека, ссылка на подборку/франшизу — к связанным произведениям. Недоступные данные не должны создавать фиктивные разделы.

**Эпизоды:** обычное нажатие выбирает серию. Правый щелчок отмечает её просмотренной/непросмотренной, не меняя выбранный эпизод. Расписание позволяет раскрыть полный список.

**Озвучка:** можно переключать переводчика и открыть сведения о рейтинге озвучек, если сайт предоставил оценки. Не все тайтлы имеют все поля.

## 6. Плеер: Anime4K и плавность

Anime4K и интерполяция движения — разные и независимые функции.

| Настройка | Что делает |
| --- | --- |
| Anime4K выкл. | Вывод без фильтра Anime4K |
| Anime4K A | Более выраженная обработка контуров |
| Anime4K B | Более мягкая обработка |
| Anime4K C | Шумоподавление/обработка пережатых исходников |
| Anime4K Light | Более лёгкий режим |
| FPS выкл. | Без дополнительной интерполяции |
| 60 / 120 FPS | Попытка повысить плавность через SVPflow/OpenCL |
| 165 FPS | Экспериментальная цель, не обещание стабильных 165 FPS |

Для начала полезно сравнить **выключено**, Light + 60 FPS и Light + 120 FPS на одном и том же видео. Если при движении заметны раздвоение, ореолы или излишняя нагрузка, уменьшите FPS или отключите интерполяцию. Anime4K способен менять текстуры и контуры; исходные детали нельзя восстановить безусловно.

Интерполяция использует OpenCL; актуальный драйвер совместимого GPU необходим. Результаты сильно зависят от исходной кадровой частоты и разрешения. Не путайте разрешение монитора 1440p с исходным разрешением потока (часто 1080p).

Пропуск опенинга — по умолчанию **85 секунд**, настраивается в пределах 1–600 секунд. Управление и курсор скрываются при бездействии во время воспроизведения и появляются после движения или паузы.

## 7. Комментарии и собственные записи

1. Войдите в аккаунт HDRezka через интерфейс приложения.
2. Откройте страницу тайтла и разверните блок комментариев.
3. Напишите текст (до 2000 символов). Поддерживаются эмодзи и ответы на существующий комментарий.
4. Нажмите **«Отправить»**. На стороне сайта могут действовать CAPTCHA, модерация или другие ограничения.

Если сайт отказал, исходный текст **не удаляется**. По возможности показывается расшифрованная причина отказа; можно открыть страницу фильма на сайте, предварительно скопировав черновик. Не нажимайте «Отправить» повторно без необходимости, если получили подтверждение модерации — комментарий может появиться позднее.

**Ваши записи** выделены акцентным фоном и надписью «Ваш комментарий», когда клиент может достоверно определить автора по доступным действиям или совпадению имени аккаунта. При входе по электронной почте имя на сайте может отличаться; не все собственные записи удаётся распознать.

## 8. Оформление

В разделе **«Оформление»** есть системная/светлая/тёмная/ручная тема, готовые двухцветные сочетания, собственный HEX, обычные/цветные метки и размеры постеров **S/M/L/XL** с предварительным просмотром. Цвет жанра относится к визуальному оформлению, а не к фильтрации каталога. Изменения сохраняются локально.

## 9. Поддержка проекта

Страница «Поддержать проект» показывает **Boosty**: `https://boosty.to/tridgi`, кнопку перехода и QR-код. QR перестраивается при изменении ширины окна. Ранее существовавшее поле «Код поддержки» убрано.

## 10. Обновление и резервные копии

1. Откройте **Настройки → Обновления**.
2. Выберите **Стабильный** для `vX.Y.Z` или **Тестовый** для `test-<sha>`.
3. Нажмите **«Проверить обновления»**.
4. При наличии обновления и доступа к GitHub подтвердите установку. Архив скачивается и проверяется по **SHA-256**.
5. Помощник завершает приложение, делает резервную копию установленного каталога и заменяет файлы. При ошибке предусмотрен откат.

Если выпуска не видно сразу, список GitHub Releases может кэшироваться. Можно открыть страницу релиза и скачать ZIP вручную. Для обновления из тестовой сборки на 2.1 выберите стабильный канал.

**Данные:** `%APPDATA%\HDREZKA-Anime4K-Motion` — настройки, история и данные пользователя. При ручном обновлении не удаляйте эту папку. Старые аккаунты из оригинального клиента не импортируются.

## 11. Частые проблемы

| Ситуация | Что проверить |
| --- | --- |
| «Ошибка сети» в каталоге | Доступность зеркала, другую категорию/жанр, настройки зеркала |
| Не отправляется комментарий | Вход в аккаунт, сообщение об отказе, CAPTCHA/модерацию на сайте |
| 120/165 FPS тормозит | OpenCL-драйвер, загрузку GPU, попробуйте 60 FPS или Off |
| Постеры/жанры ведут себя необычно | Размер окна, масштаб Windows, актуальность тестового/стабильного выпуска |
| Нет обновления | Выбранный канал, GitHub, кэш результатов (можно скачать ZIP вручную) |
| Не запускается после распаковки | Целостность ZIP, наличие `runtime`/`motion`/`shaders`, Windows x64 |
| Обновление не завершилось | `%APPDATA%\HDREZKA-Anime4K-Motion\updater.log`, резервную копию папки |

**Техническая диагностика:** [docs/UPDATER.md](UPDATER.md), [docs/BUILD.md](BUILD.md). Не публикуйте cookies, пароли, данные сессии или приватные пути из журналов при обращении за помощью.

## 12. Важные ограничения

Автоматизированные тесты проверяют код, разбор ответов сайта, сборку, архив и сценарий резервного копирования, но не подтверждают внешний сайт, каждую версию Windows, каждое сочетание DPI/GPU или фактическую работу CAPTCHA. Некоторые страницы сайта могут работать только в браузере.
