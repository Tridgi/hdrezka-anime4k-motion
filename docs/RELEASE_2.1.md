## Коротко о выпуске

Версия 2.1 — крупное обновление поверх публичной 2.0.0. Основное внимание уделено удобству поиска и просмотра, устойчивости интерфейса при изменении размеров окна, отображению данных сайта, авторизации и комментариям. Поддержка Anime4K, SVPflow и привычного отдельного плеера сохранена.

## Фильтрация жанров: что исправлялось

В ранних сборках жанры отображались, но клиент использовал жёсткое допущение, что каждая ссылка содержит `/genre/`. Реальные страницы могут использовать короткие адреса, например `/series/melodrama/`. Результатом было локальное исключение, показанное как «Ошибка сети».

В 2.1 реализованы:
1. получение жанров из навигации нужного типа контента на текущем зеркале, затем резервный поиск по HTML;
2. проверка только безопасных внутренних маршрутов вместо старой проверки обязательного сегмента `/genre/`;
3. загрузка страниц с выбранными фильтрами и подавление устаревших запросов при быстрых переключениях;
4. тесты путей и парсинга на разных схемах URL.

**Граница гарантии:** реальные серверные ограничения (блокировка, редиректы, CAPTCHA, недоступность конкретного жанра) исправить локально не всегда возможно. Здесь тестируется совместимость с известными форматами страниц.

## Комментарии: что исправлялось

Клиенту требуются form-urlencoded POST в `ajax/add_comment/`, поле комментария, ID тайтла и служебные параметры. В коде добавлены cookie `allowed_comments=1`, `X-Requested-With`, Origin и Referer, как ожидают известные клиенты сайта. Ошибки `message` могут приходить массивом, строкой или строкой с вложенным JSON — теперь они декодируются вместо вывода `\\u041...`.

При успешном ответе сайт может сообщить о модерации; черновик не удаляется при отказе. Собственные комментарии подсвечиваются по элементам интерфейса, доступным автору, либо (где допустимо) совпадению отображаемого имени.

**Граница гарантии:** невозможно принудительно обойти ограничения сайта. Успех реальной публикации при конкретном зеркале/аккаунте не подтверждается из CI.

## Плеер и его ограничения

Плеер, сохранение позиции просмотра и пользовательские настройки продолжают работать. Anime4K и плавность задаются независимо. Режимы интерполяции 60/120/165 FPS зависят от OpenCL-драйвера и GPU; 165 FPS является экспериментальным. Тесты размеров SVPflow и проверки переключений ограничивают известные регрессии, но не заменяют испытаний на каждом видеопотоке.

## Установка и переход с 2.0 / тестовых сборок

1. Установите Windows x64, убедитесь в наличии Direct3D 11 и подходящего OpenCL при использовании плавности.
2. Скачайте архив **`HDREZKA-Anime4K-Motion-2.1.0-win-x64.zip`** из релиза. SHA-256 приведён в `SHA256SUMS.txt`.
3. Извлеките **всё содержимое** в отдельный каталог и запустите `HDREZKA.App.exe`.
4. Если переходите из тестовой сборки, выберите **стабильный канал** в настройках или выполните ручную распаковку после закрытия приложения.
5. Не удаляйте `%APPDATA%\HDREZKA-Anime4K-Motion`: здесь настройки, данные входа и история, а не внутри ZIP.

Переход со старого приложения eddinwork/HDREZKA не переносит cookies и аккаунт автоматически. Повторный вход выполняется пользователем.

## Комплект поставки

- ZIP для Windows x64 с self-contained .NET/Windows App SDK, бинарником и необходимыми зависимостями;
- файл `SHA256SUMS.txt` с контрольной суммой;
- GitHub автоматически предоставляет исходный архив тега;
- исходные лицензии и уведомления — в [THIRD_PARTY.md](../THIRD_PARTY.md).

**Нет:** логинов, паролей, cookies, пользовательской истории, тестовых видеороликов и инструментов несанкционированного доступа.

## Контроль качества перед публикацией

| Проверка | Где и что проверяется |
| --- | --- |
| Unit-тесты ядра | `dotnet test tests/HDREZKA.Tests/HDREZKA.Tests.csproj -c Release` — парсеры, ответы API, версии |
| UI smoke | `scripts/test-details-pages.py` — структура XAML, обработчики, известные регрессии страниц |
| Низкое разрешение | `scripts/test-motion-resolutions.py` — подготовка кадров SVPflow |
| Сборка | Windows x64 `dotnet publish` self-contained |
| Архив и SHA-256 | `package.ps1`, контрольная сумма ZIP |
| Установщик | `scripts/test-updater.ps1` — синтетическое обновление, backup, rollback |

**Нельзя заменить автоматикой:** визуальную проверку WinUI при разных DPI, реальную авторизацию/комментарии на стороне сайта и фактическое воспроизведение на каждом GPU. Эти проверки остаются рекомендацией пользователям тестовых сборок.
