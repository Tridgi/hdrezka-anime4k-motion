# Changelog

## [Unreleased]

Планируемые изменения для следующего стабильного релиза (публикуются после проверки и слияния в `main`):

- Цветовые схемы оформления стали чистыми двухцветными плитками 50/50 без тёмного слоя и дополнительной плашки под названием: крупный контрастный текст по центру, отметка выбранной схемы.
- Исправлена высота текстовой части MovieCard: один или два ряда названия больше не сдвигают постеры относительно соседей; карточки в каталоге, поиске, закладках и на главной закреплены сверху.
- Расширены внутренние интервалы в горизонтальных лентах, оставлен запас для плавного увеличения постеров к зрителю (1,055x), чтобы изображение не обрезалось верхней границей. Финальные карточки перехода к каталогу выровнены по постерам.
- Рейтинги R, IMDb и КП в предпросмотре главной оформлены такими же фирменными значками, как на странице фильма.
- Баннер «Сейчас в топе» меняется раз в 14 секунд вместо 10, останавливает автопрокрутку при наведении мыши; оценка HDREZKA на баннере получает красно-жёлто-зелёную шкалу.
- Убрана двойная подписка на события раскрытия/скрытия боковой панели, чтобы синхронизировать иконку без дублирующихся обработчиков.


- Страница «Подборки» теперь загружает все страницы каталога /collections/page/N/ (до безопасного лимита), удаляет дубликаты и останавливается на пустой, повторной или недоступной странице.
- Страница фильма показывает только реально существующие ссылки «Все части франшизы», «В подборках», «Из серии». По нажатию открываются связанные тайтлы или исходные коллекции и рейтинговые списки; отсутствующие блоки не показываются.
- Цветные жанровые плашки открывают каталог по конкретной ссылке жанра, где есть видимый фильтр и возможность сброса.
- Страница человека переработана: адаптивное фото и данные, раскрывающиеся разделы фильмографии с сеткой постеров, без внутренних скроллбаров.
- Исправлены повторяющиеся русские ключи локализации Collections.* и перенесены украинские строки в украинский словарь; добавлены регрессионные тесты на уникальность всех языковых ключей.
- Добавлены parser/xaml-тесты на пять страниц коллекций, связи франшиз, списки «Из серии», переходы и отсутствие блоков при неполных данных.


- Каталог: выпадающий список «Новинки/Популярное/Скоро/Сейчас смотрят» перемещён первым элементом в один ряд с кнопками категорий; изменена только компоновка, логика фильтров сохранена.
- В каталоге над сеткой карточек появляется всплывающий предпросмотр «О фильме» с R/IMDb/КП, описанием, разноцветными названиями жанров, режиссёрами и актёрами. Быстро показываются доступные сведения, подробности подгружаются только после устойчивого наведения; предпросмотр кэшируется (не более 24), обрезание краями экрана предотвращено.
- «Подборки»: убрана горизонтальная полоса карточек над фильмами и автозапуск первой подборки; теперь сначала открывается адаптивная сетка подборок со строкой поиска по названию. Выбранная подборка открывается отдельным экраном с заголовком, количеством и кнопкой «Все подборки». Недоступная/удалённая подборка возвращает к выбору, а пустое состояние не перекрывает навигацию.
- Раздел «Оформление» теперь включает живой 2:3 образец постера-заглушки. При смене размера S/M/L/XL его ширина и высота автоматически меняются по общим PosterMetrics, выводятся пиксели; используются текущие акцентные цвета, без загрузки изображений.


- У постеров рейтинг HDREZKA больше не появляется после наведения. Плашка показана только тогда, когда оценка уже содержится в каталожных данных; отложенные запросы подробностей по-прежнему питают отдельную карточку предпросмотра.
- Исправлено листание шести главных подборок: HorizontalScrollBarVisibility возвращён в Hidden вместо Disabled (WinUI Disabled блокирует движение ленты). Кнопки влево/вправо снова перемещают список.
- Колесо мыши без Shift прокручивает страницу вертикально; Shift + колесо листает ленту под курсором горизонтально. Прокрутка управляется на уровне внутреннего контейнера для подавления встроенной реакции вложенного ScrollViewer.
- При наведении на постер больше не появляется серое состояние системной кнопки: отдельный прозрачный Button ControlTemplate оставляет видимым сам постер и системный фокус клавиатуры.
- «Сейчас в топе»: вместо мелкой надписи с номером используется большой номер Top 5 слева за постером, в стиле рейтинговых подборок. Положение номера и постера адаптируется к размеру окна.


- Все жанры фильма теперь получают различимые текстовые оттенки из общей адаптивной палитры: одинаковые/слишком близкие оттенки в одной карточке автоматически раздвигаются, а нейтральная тема остаётся сдержанной. Палитра едина для страницы фильма, наведения на рекомендациях и главной.
- Рейтинг HDREZKA на странице фильма и в предпросмотре теперь окрашивается по числовой шкале 0–10 — красный → янтарный → зелёный, с небольшим внутренним градиентом. Другие рейтинги не меняются.
- Рейтинг на постере отображается при наличии оценки из каталога и добавляется после загрузки подробностей при наведении; нет массовых лишних запросов к сайту.
- На постерах при наведении больше нет серого затемнения: остаются плавное увеличение и иконка воспроизведения.
- Шесть горизонтальных лент теперь не прокручиваются колесом или свайпом вбок: стрелки меняют позицию программно, вертикальный скролл страницы сохраняется.
- Завершающие карточки подборок увеличены на 30% по ширине, получили двухцветный фон из выбранной темы, крупную подпись «Вся подборка» и пояснение «Открыть каталог».


- Уточнена совместимость переключаемых иконок панели с WinUI: оба варианта размещены внутри одного контейнера Button; добавлена регрессионная проверка структуры XAML.

- В рекомендациях жанры отображаются цветным текстом без плашек, а режим «Обычное» возвращает нейтральный текст.

- Шесть подборок главной страницы стали однорядными горизонтальными каруселями со стрелками, скрытыми полосами прокрутки и завершающей карточкой «Посмотреть все» для перехода в соответствующий каталог.

## v2.0.0

First cleaned public release of HDREZKA Anime4K Motion, based on HDREZKA commit a4676233114dbc0af1221826ae8440d9293226bb.

- Embedded Direct3D 11 libmpv rendering and Anime4K A/B/C/Light.
- Independent OpenCL motion interpolation targets: 60, 120, experimental 165 FPS.
- Configurable opening skip and inactivity cursor/control hiding.
- Fixed delayed access violation after disabling FPS by pinning worker runtime modules for the process lifetime.
- Hidden accidental global keyboard accelerator tooltips over the video.
- Separate clean app data folder; project-specific update link; no bundled personal state.

Earlier v1/v2/v2.1 names referred to local development builds; they are not separate public releases.
