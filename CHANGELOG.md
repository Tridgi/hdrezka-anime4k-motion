# Changelog

## [Unreleased]

Планируемые изменения для следующего стабильного релиза (публикуются после проверки и слияния в `main`):

- Дополнительная полировка главной: одинаковый цвет жанра вне зависимости от позиции в списке; контрастная подпись оранжевых рейтингов и корректный вертикальный отступ рейтинга, когда нет сезонной плашки.
- У иконки боковой панели обновляется состояние не только после клика, но и при адаптивном изменении ширины окна.
- Исправлена структура WinUI XAML кнопки панели: обе иконки помещены в один Grid; добавлен регрессионный тест на один корневой элемент содержимого кнопки после сбоя XamlCompiler.exe.


- Плитки сочетаний цветов на странице «Оформление» целиком залиты двумя выбранными оттенками (чёткое деление 50/50); крупное название по центру, выделение выбранной схемы.
- В рекомендациях жанры отображаются цветным текстом без плашек, а режим «Обычное» возвращает нейтральный текст.
- Иконка боковой панели показывает отдельные состояния открытого и закрытого меню.
- Постеры показывают небольшой рейтинг HDREZKA над бейджем сезона: цвет от красного через оранжевый к зелёному.
- Главный баннер «Сейчас в топе» центрирован, стрелки вынесены из зоны постера, добавлено описание справа, автосмена замедлена до 10 секунд, активная точка больше не растягивается в овал.
- Шесть подборок главной страницы стали однорядными горизонтальными каруселями со стрелками, скрытыми полосами прокрутки и завершающей карточкой «Посмотреть все» для перехода в соответствующий каталог.
- Компонент MovieCard резервирует фиксированную высоту под двухстрочные заголовки: постеры выровнены. Анимация при наведении увеличивает карточку из центра, а не поднимает её к обрезающей границе.
- Добавлен быстрый предпросмотр фильма поверх главной страницы при наведении на карточку: рейтинги, краткое описание, цветные текстовые жанры, режиссёры и актёры подгружаются по требованию с ограниченным кэшем.


- В заголовке приложения утончены векторные иконки «Назад» и «Боковая панель»; аппаратные боковые кнопки мыши XButton1/XButton2 переключают историю приложения назад и вперёд, в том числе над вложенными контролами.
- Новый раздел «Оформление» в боковом меню непосредственно перед «Поддержкой проекта». Тема Windows, ручная яркость, 12 акцентных пар, HEX-цвет, обычные/цветные плашки и размер постеров перенесены из «Настроек»; изменения применяются сразу, сохраняются и показываются на предпросмотре, предусмотрен сброс.
- Вертикальные системные полосы прокрутки скрыты во всех основных разделах каталога, карточек, поиска, личного кабинета, настроек и диалогов без отключения прокрутки колесом, клавишами или тачпадом.
- Предпросмотр рекомендаций теперь подписан «О фильме» и показывает R/IMDb/КП отдельными плашками с логотипами, а жанры — адаптивными цветными метками. Палитра совпадает с выбранным режимом «Цветное/Обычное» и ручным акцентом.


- Вернул компактное расписание из пяти строк прямо на карточку фильма; кнопка «Показать всё» открывает отдельное широкое окно с аккуратной группировкой серий, датами, нумерацией и скрытой полосой прокрутки.
- Предпросмотр в рекомендациях теперь отдельный элемент поверх всей страницы, без ToolTip/Flyout внутри ListView: рамка не обрезается, позиция ограничена окном, первые сведения показываются без ожидания ответа сети.
- Обновил отправку комментариев: проверка реального подтверждения сервера (true / 1 / «1»), распознавание отказов, вывод причины ошибки вместо общей заглушки, сохранение текста. Если публикация требует сайта, добавлена кнопка открыть страницу через HTTPS с копированием черновика.
- Добавлены тесты для серверных ответов отправки комментариев и регрессионные проверки расписания и предпросмотра.


- Новые комментарии: аккуратные карточки с аватарами-инициалами, вложенными ответами, кнопками лайка и ответа; мультстрочный редактор с эмодзи, счётчиком 2000 символов, отменой ответа, сохранением черновика при ошибке отправки.
- Сортировка уже загруженных комментариев по порядку сайта, лайкам, обратному порядку и автору; дальнейшие страницы подгружаются и пересортировываются без повторных запросов.
- «Показать всё расписание» раскрывает весь список внутри страницы без модального окна и дополнительной полосы прокрутки; строки с датами оформлены как компактные карточки, добавлена кнопка свернуть.
- Предпросмотр рекомендаций перенесён из обрезающегося WinUI ToolTip в адаптивный скруглённый Flyout с автоматическим размещением у краёв окна. Краткая карточка появляется быстро, подробная информация кэшируется.


- Исправлен прыжок к началу страницы при ПКМ по серии: отметка обновляется на самой кнопке, без пересоздания списка; позиция прокрутки сохраняется.
- Японский флаг и цветной бабл больше не имеют чёрного фона: бело-розовая основа, красный круг и контрастная подпись.
- Блок «Смотрите также»: пять компактных карточек на широкой странице, увеличенные промежутки, стрелки по центру слева и справа, выравненный заголовок. При остатке из четырёх тайтлов следующая страница показывает четыре.
- При задержке курсора на карточке рекомендации появляется оформленная всплывающая информация с рейтингами, описанием, жанрами, режиссёром и актёрами; данные лениво подгружаются с сайта и кэшируются в ограниченном объёме.
- «В ролях» выровнено по верхней строке плашек, а не по центру всех актёров.


- Исправление возможного вылета при входе на страницу фильма: рекомендации теперь управляются виртуализированным WinUI ListView, а не удалением/созданием MovieCard внутри SizeChanged. Перекомпоновка выполняется отдельно в UI-очереди с ограничением количества карточек, на ошибках строится безопасный экран и пишется crash.log.
- Настройка уведомлений о новых сериях и кнопка ручной проверки перенесены из «Настроек» прямо на страницу «Уведомления», параметры сохраняются как прежде.
- Добавлена проверка XAML и обработчиков событий в CI, включая защиту от возврата опасной синхронной модификации карусели.


- Карточка тайтла: японский флаг с белой основой; компактная квадратная кнопка ▶ в строке озвучки; бабл с датой выхода рядом со странами из уже разобранных данных сайта.
- Блок «Смотрите также» в отдельной карточке: до 3 увеличенных постеров, перелистывание по страницам стрелками, адаптация до 2/1 в узком окне, без горизонтального скролла.
- Комментарии перенесены в самый низ страницы после рекомендаций: центрированная кнопка «Смотреть комментарии» / «Скрыть комментарии», сохранена загрузка и отправка.
- Вертикальная полоса прокрутки страницы карточки скрыта, колесо мыши и сенсорная прокрутка продолжают работать.

- Исправление закрытия WinUI при обновлении и CI-проверка замены файлов.

## v2.0.0

First cleaned public release of HDREZKA Anime4K Motion, based on HDREZKA commit a4676233114dbc0af1221826ae8440d9293226bb.

- Embedded Direct3D 11 libmpv rendering and Anime4K A/B/C/Light.
- Independent OpenCL motion interpolation targets: 60, 120, experimental 165 FPS.
- Configurable opening skip and inactivity cursor/control hiding.
- Fixed delayed access violation after disabling FPS by pinning worker runtime modules for the process lifetime.
- Hidden accidental global keyboard accelerator tooltips over the video.
- Separate clean app data folder; project-specific update link; no bundled personal state.

Earlier v1/v2/v2.1 names referred to local development builds; they are not separate public releases.
