# Changelog

## [Unreleased]

Планируемые изменения для следующего стабильного релиза (публикуются после проверки и слияния в `main`):

- Исправлен прыжок к началу страницы при ПКМ по серии: отметка обновляется на самой кнопке, без пересоздания списка; позиция прокрутки сохраняется.
- Японский флаг и цветной бабл больше не имеют чёрного фона: бело-розовая основа, красный круг и контрастная подпись.
- Блок «Смотрите также»: пять компактных карточек на широкой странице, увеличенные промежутки, стрелки по центру слева и справа, выравненный заголовок. При остатке из четырёх тайтлов следующая страница показывает четыре.
- При задержке курсора на карточке рекомендации появляется оформленная всплывающая информация с рейтингами, описанием, жанрами, режиссёром и актёрами; данные лениво подгружаются с сайта и кэшируются в ограниченном объёме.
- «В ролях» выровнено по верхней строке плашек, а не по центру всех актёров.


- Исправление возможного вылета при входе на страницу фильма: рекомендации теперь управляются виртуализированным WinUI ListView, а не удалением/созданием MovieCard внутри SizeChanged. Перекомпоновка выполняется отдельно в UI-очереди с ограничением количества карточек, на ошибках строится безопасный экран и пишется crash.log.
- Настройка уведомлений о новых сериях и кнопка ручной проверки перенесены из «Настроек» прямо на страницу «Уведомления», параметры сохраняются как прежде.
- Добавлена проверка XAML и обработчиков событий в CI, включая защиту от возврата опасной синхронной модификации карусели.


- Карточка тайтла: японский флаг с белой основой; компактная квадратная кнопка ▶ в строке озвучки; бабл с датой выхода рядом со странами из уже разобранных данных сайта.
- Блок «Смотрите также» в отдельной карточке: до 3 увеличенных постеров, перелистывание по страницам стрелками, адаптация до 2/1 в узком окне, без горизонтального скролла.
- Комментарии перенесены в самый низ страницы после рекомендаций: центрированная кнопка «Смотреть комментарии» / «Скрыть комментарии», сохранена загрузка и отправка.
- Вертикальная полоса прокрутки страницы карточки скрыта, колесо мыши и сенсорная прокрутка продолжают работать.
- Адаптивная верхняя и нижняя панели плеера; меню ✨ Anime4K/плавности и ⚙ настроек воспроизведения.
- Статистика воспроизведения, выбор скорости, кнопка пропуска опенинга; исправления DPI масштабирования.
- Выбор стабильного и тестового каналов обновлений; SHA-256, резервная копия, автоматический перезапуск.
- Исправление закрытия WinUI при обновлении и CI-проверка замены файлов.
- Копирование информации о текущей сборке; исправленные ссылки поддержки проекта.
- Исправление обрезания процентов в окне рейтинга озвучек.
- Обновлённый рейтинг озвучек: адаптивная ширина, фиксированная колонка процентов, место под прокрутку и читаемые подписи.
- Новая карточка произведения: кнопки трейлера, просмотра, закладок и отслеживания под постером; рейтинги с мини-логотипами, возрастная маркировка, плашки стран/жанров/длительности, аккуратные режиссёры и актёры с раскрытием списка.
- Описание во всю ширину с раскрытием, отдельные списки сезона и озвучки, компактные серии с переносом до десяти на строку.
- В настройках «Оформление карточки»: нейтральные и цветные плашки, независимые от светлой/тёмной темы; сохраняется в settings.json.
- Окно рейтинга озвучек теперь показывается в собственном полнооконном модальном слое RootGrid: точное центрирование относительно приложения независимо от NavigationView, адаптация при изменении размера окна, закрытие по Escape и кнопке.
- Кэш GitHub Releases для проверки обновлений и истории версий с обработкой лимитов API 403/429.
- Раздел «Поддержка проекта» вынесен из настроек на отдельную страницу над уведомлениями; Boosty, код поддержки и привилегии сохранены.
- Выпадающий список сезона перенесён в начало строки перед кнопками выбора серий.
- История версий внутри приложения с описанием опубликованных релизов.
- Сохранение выбранной плавности при смене качества/CDN: проверка видеофильтра при открытии нового потока; диагностика фактического подключения и частоты FPS.
- Перенос ✨ и ⚙ из верхней/левой части плеера в нижний правый блок рядом с полноэкранным режимом; улучшение компактной компоновки.
- Не отключать плавность глобально из-за обычных ошибок видеоссылок; при подтверждённом сбое SVPflow временно отключать только проблемный поток.
- При отсутствии FPS в метаданных контейнера использовать корректную частоту VideoNode, если она известна; неизвестную частоту не угадывать.
- Исправлена подготовка кадров SVPflow для 426×240 и 854×480: чётные размеры после Halve, без изменения видимого размера видео; добавлены тесты 60/120/165 FPS.
- Навигация «Назад» и сворачивание бокового меню перенесены в заголовок основного окна, поиск теперь первый элемент боковой панели.
- Исправлено направление стрелки «Назад» и добавлен компактный значок боковой панели в стиле редактора.
- Из поддержки проекта убраны старый TON-кошелёк, его QR-код и кнопка копирования; Boosty и коды поддержки сохранены.
- В настройках главной страницы добавлена сортировка блоков перетаскиванием с ручкой ≡ и сохранением порядка; галочки видимости не меняют порядок.

## v2.0.0

First cleaned public release of HDREZKA Anime4K Motion, based on HDREZKA commit a4676233114dbc0af1221826ae8440d9293226bb.

- Embedded Direct3D 11 libmpv rendering and Anime4K A/B/C/Light.
- Independent OpenCL motion interpolation targets: 60, 120, experimental 165 FPS.
- Configurable opening skip and inactivity cursor/control hiding.
- Fixed delayed access violation after disabling FPS by pinning worker runtime modules for the process lifetime.
- Hidden accidental global keyboard accelerator tooltips over the video.
- Separate clean app data folder; project-specific update link; no bundled personal state.

Earlier v1/v2/v2.1 names referred to local development builds; they are not separate public releases.
